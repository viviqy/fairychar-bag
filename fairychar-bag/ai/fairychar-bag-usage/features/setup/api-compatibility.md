## 用途与采用边界

**采用状态：查询规则**。按需查签名，不把索引存在理解为行为可靠性或接入推荐。

本页是该功能的使用说明；下列代码片段依赖业务类型时需替换为项目已有定义，完整 Java 文件另有标注。

## 如何查询

需要确认 import、重载、注解默认值时进入 [API 目录](../../api/README.md)，只加载对应包或类型。方法按声明类型列出；继承方法沿父类/接口导航，第三方继承 API 不展开。签名代码块不是可整段复制的 Java 文件。

文档与实际 JAR 不一致时停止采用冲突用法，先核对版本；不臆造方法，不要求调用方取得源码。

## 索引范围

包含约定调用方范围内的 public 类型、构造器、声明方法、字段、枚举常量、注解属性及生成成员。排除 `com.fairychar.bag.aop` 包及子包、约定内部类型和废弃组件；不索引 POM、依赖版本、非 public 成员、构建发布流程。框架回调可查签名，不等于应由业务手动调用。

## 行为不明确时

功能页未闭合的输入、输出、失败或资源责任，不按名称补全语义，不以“待测试”作为生成生产接入代码的理由。优先明确的业务替代；必须采用时明确缺少哪项契约。环境测试确认集成，不用于反推基本语义。仅签名可查的入口不默认采用。
