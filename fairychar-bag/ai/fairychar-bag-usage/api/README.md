## 覆盖边界

- 在下述排除范围之外，包含外部可访问的 public 顶层与嵌套类型、显式及生成的 public 构造器、当前类型声明的 public 方法与字段。
- 包含接口 default 方法、注解属性及默认值、枚举常量、Lombok 生成方法与枚举生成方法。
- 排除不可访问外部类中的类型、匿名类、局部类、synthetic 与 bridge 成员，以及非 public 成员。
- 排除 `com.fairychar.bag.aop` 包及子包的内部实现，即使类型或方法为 public 也不作为调用方 API。
- 排除约定的内部类型、废弃组件及其嵌套类型，范围见 [覆盖口径](../features/setup/api-compatibility.md)。
  请求日志和方法锁的使用方式见 [请求日志](../features/web/request-logging.md) 与 [方法锁](../features/locking/method-lock.md)；注解、配置和扩展接口仍保留。
- 继承方法通过父类/接口导航查找，不重复计数；第三方父类的 API 不展开，POM 与依赖坐标不索引。
- 不主动读取静态字段值；本索引不是线程安全、默认配置或运行行为证明。
